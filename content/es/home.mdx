# Bienvenido a Big Walk

Big Walk se disfruta más cuando queda espacio para deambular. Esta wiki reúne notas claras para esos momentos en que un lugar parece conocido, un rompecabezas no encaja o un sendero nuevo resulta imposible de ignorar.

Empieza con los [consejos iniciales](/es/beginner-tips) para una lista tranquila del primer día y consulta el [recorrido guiado](/es/walkthrough) solo cuando quieras un mapa. Cada guía intenta conservar el placer de descubrir tu propio camino.
