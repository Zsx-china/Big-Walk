## Crossplay status

Big Walk supports cross-platform multiplayer between PC, PS5, and Nintendo Switch 2. The supplied Official FAQ describes crossplay as fully supported across every launch platform, so the platform a player owns does not prevent that player from joining a supported group. It also says that multiplayer features do not have platform-specific restrictions, which means this page treats the three named platforms as one shared multiplayer pool rather than three separate pools. This is a multiplayer compatibility statement, not a promise that save files, achievements, trophies, menus, or every account feature move from one platform to another.

Within the supplied facts, the phrase fully supported has a precise multiplayer meaning. A PC, PS5, or Nintendo Switch 2 player may enter one shared session through the same Join Code rule, and the Official FAQ says the code works regardless of which of those platforms belongs to the host or the guest. The same FAQ identifies proximity-based voice chat as cross-platform and reports no platform-specific restrictions on multiplayer features, so a group should not split itself into platform-specific session plans when every member is on one of the three named platforms. At the same time, the supplied IGN research keeps the persistent part separate: the shared session does not move saves, achievements, or trophies from one platform record to another, even during a confirmed shared cross-platform session.

## Supported platforms

The supported platforms named in the supplied research are PC through Steam, PlayStation 5, and Nintendo Switch 2. GamesRadar identifies those three platforms and says players on different ones can enter the same session with Join Codes, while the supplied Official FAQ independently confirms crossplay across all launch platforms. A group can therefore combine the named platforms instead of requiring everyone to purchase or play on the same one, and the supplied material says there is no platform restriction on the multiplayer features themselves. This guide is limited to the named launch-platform group and does not add unsupported platform coverage.

## Join Codes

Join Codes are the stated bridge between players on different supported platforms: a host starts a multiplayer session, and guests use that session's code to enter it. The supplied Official FAQ says that a Join Code works regardless of whether the host or guest is on PC, PS5, or Nintendo Switch 2, so the code is not limited to a same-platform invitation. The code connects a player to the current host session; it does not turn an account, save file, achievement, or trophy into shared cross-platform data. **Pending confirmation:** the exact code format, the screen where it appears, the entry menu, and the timing for creating or replacing a code are not included in the supplied research.

## Starting a session

To set up a cross-platform group, first decide which player is hosting the intended multiplayer session, then share that host's Join Code with the other supported-platform players. The supplied FAQ makes the important boundary clear: the host's platform does not create a platform lock for the guests, so a PC host and console guests, or a console host and PC guests, use the same crossplay rule. Guests enter the code for the host's existing session rather than treating it as a reward key or as a transfer tool for their own platform data. **Pending confirmation:** the exact start-session action, menu labels, account requirements, version checks, regional behavior, error messages, and recovery steps have not been supplied, so they are not presented as instructions here.

## Twelve-player sessions

The supplied IGN research gives one group-size limit: up to 12 players total can be in a session regardless of the platform mix. That total can contain any combination of the three confirmed platforms, so the relevant limit is the whole session count rather than a separate PC, PS5, or Nintendo Switch 2 quota. For example, the source material explicitly describes a mixed twelve-player group as valid, but the useful rule is simply to count every participant toward the same shared maximum. This page does not add a separate party-size, matchmaking, queue, or reservation rule because those details are not among the facts supplied for this guide.

## Proximity voice chat

The supplied Official FAQ says proximity-based voice chat works cross-platform too, so the distance-sensitive voice feature belongs to the same shared multiplayer experience as the Join Code session. A player on one of the three confirmed platforms can therefore take part in that feature with friends on the other confirmed platforms without the guide adding a platform exception. This confirms cross-platform availability of proximity voice chat, not the technical settings that each device might expose outside the game. **Pending confirmation:** audio-device setup, accessibility options, moderation controls, network troubleshooting, and any menu-level voice settings were not included in the supplied information.

## Saves and achievements

Crossplay lets a mixed group play together, but the supplied IGN research says saves are platform-specific, so a Steam save does not transfer to console and a console save is not described as moving to PC. Achievements and trophies are also platform-specific in that research, which means playing in the same session does not merge those records or turn one platform's award into another platform's award. The Join Code is only a way to enter the multiplayer session; it does not carry a save, progress record, achievement, or trophy between platforms. **Pending confirmation:** the supplied material does not define every save edge case, host-save outcome, restoration rule, or ownership detail, so players should use the separate save guide for the current boundary of that topic.

## Limits and FAQ

The practical answer is straightforward: use the three confirmed platforms, join the intended host through its Join Code, and count every participant toward the shared 12 players total. Do not use crossplay as a reason to assume that a save, achievement, or trophy will follow a player to another platform, because the supplied research says those remain platform-specific.
