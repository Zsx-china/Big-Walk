Big Walk uses **join codes** to get players into the same session. It is
the only way to group up across platforms, and it works on every platform
with no settings to flip.

## What a join code is

A join code is a short, session-scoped string generated when the host
starts a walk. It is **not** a redeem code: it unlocks no items, cosmetics,
or currency. It only connects a player to an active session.

**Is "join code" the same as "session code", "lobby code" or "server
code"?** Yes — they're all the same thing. Big Walk calls it a join code,
and because one code is generated per session, players online also call it
a session, lobby, or server code. Don't be thrown off by a guide or chat
using a different name — the entry point is always **Join Game → Join
Code**.

## How to join with a code

<StepList>
  <Step title="Host starts the walk">
    One player creates the session from the main menu.
  </Step>
  <Step title="Host opens the pause menu">
    The join code is displayed in the bottom-left corner of the pause menu.
  </Step>
  <Step title="Choose Join Game → Join Code">
    Each other player selects **Join Game**, then **Join Code** from the
    main menu.
  </Step>
  <Step title="Enter the code">
    Type the code the host reads out. No accounts, no invites, no friend
    requests.
  </Step>
</StepList>

<Callout type="tip" label="READ IT TWICE">
  Codes are short but easy to misread. Read the code twice before everyone
  types it — a single wrong letter stalls the whole lobby.
</Callout>

## How the host finds & shares the code

- **Find it:** pause the game — the session code sits in the **bottom-left
  corner** of the pause menu, and it stays there for the whole walk.
- **Read it aloud:** the fastest way for a mixed-platform group.
- **Send it in text:** the code works on PS5, Switch 2, PC and Mac alike,
  so paste it into a chat or Discord and everyone types it in without
  mishearing.
- **A new walk = a new code:** codes are session-scoped. If the host
  closes and reopens the walk, a fresh code appears — resend it.

## Join codes vs. friends lists

- **Join code** — works across platforms (PC, Mac, PS5, Switch 2). The
  only option for a mixed-platform group.
- **Friends list** — works only on the same platform network. Console and
  PC friends lists don't sync across platforms in-game.

## Frequently asked

### Where does the host find the join code?

The host opens the pause menu; the session code is shown in the bottom-left
corner of the screen.

### Why isn't my join code working?

Check the host's game version matches yours, confirm the session is still
open, and have the host re-read the code. Codes are session-scoped, so
closing and reopening the walk generates a new one.

### Does Big Walk have redeem codes?

No. As of August 2026 there are no redeem codes — only session-based join
codes. Any string claimed to unlock items or cosmetics should be treated as
unverified.

### How many players can join with a code?

A session fills to 12 walkers regardless of how each player joins.

### Do I need a Big Walk account?

No. Join codes need no account and no friend request.

### The room is full — how do we get in?

A session fills at 12 walkers. The host has to close and reopen the walk
(which makes a new code) or someone has to leave before the rest can join.

### How do I send the join code to a friend?

The host finds it in the bottom-left corner of the pause menu. Read it
aloud, or paste it into a chat — the same code works on PC, Mac, PS5 and
Switch 2.
