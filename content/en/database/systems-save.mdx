Big Walk is a co-op walk-and-talk game played in hosted sessions, and the
short version of saving is: **the host's session owns the save.**

## What is confirmed

- The host controls the active session and its save decisions.
- Guest progress and shared milestones are recorded in the context of the
  host's save — there is no separate "guest account" progress to take home.

<Callout type="warn" label="BEFORE A LONG WALK">
Ask the host what will be saved before a long outing. If the group is
planning to continue the island across sessions, the same host should
usually keep hosting — otherwise the walk's continuity depends on what the
next host has in their save.
</Callout>

## What remains unconfirmed

Early community reporting has not yet confirmed the edge cases:

- What happens to a session's progress if the host disconnects mid-walk.
- Whether progress can be transferred between hosts or platforms.
- How save data behaves across game updates.

These are marked as open questions rather than answered — treat any specific
claim about them as "needs testing" until confirmed in-game.

## Practical rules for groups

1. Agree on a **permanent host** if the group plans multiple sessions on the
   same island.
2. Before a session ends, confirm what was saved with the host.
3. Don't plan around save tricks or transfer workarounds until they're
   confirmed — the game is a walk, not a save file.
