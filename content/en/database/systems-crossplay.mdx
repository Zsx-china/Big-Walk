Big Walk supports full crossplay: **PC (Steam/Epic), Mac, PlayStation 5,
and Nintendo Switch 2** can all share one island. The catch is that
cross-platform sessions use **join codes**, not friends lists — because
platform friends lists don't talk to each other.

## How joining works

### Same platform, same friends network

Host the walk, then everyone else goes to **Join Game** and picks the host
from the friends list. Big Walk pulls your platform friends into the join
screen automatically.

### Mixed platforms — join codes

This is the path for any group that spans PC, PS5, and Switch 2:

<StepList>
  <Step title="Host starts the walk">
    One player creates the session from the main menu.
  </Step>
  <Step title="Host opens the pause menu">
    The session's **join code** is displayed in the bottom-left corner of
    the pause menu.
  </Step>
  <Step title="Everyone else selects Join Game → Join Code">
    Enter the code the host reads out — no accounts, no invites, no friend
    requests.
  </Step>
  <Step title="Walk together">
    The session fills as players join, up to 12 walkers.
  </Step>
</StepList>

<Callout type="tip" label="LOBBY ETIQUETTE">
Read the code twice. It's usually short, but a misread letter in a
twelve-person lobby costs everyone a minute of "wait, whose code is this
again?"
</Callout>

## Frequently asked

### Is crossplay on by default?

Join codes work on every platform with no settings to flip. If your group
is all on one platform, the friends list path is also available.

### Does anyone need a paid online subscription?

Standard platform rules apply (e.g. PlayStation Plus on PS5). No
Big-Walk-specific account or subscription exists.

### Can a session mix friends-list and code joiners?

Yes — once a session exists, players can join however the client offers it,
and the session fills to 12 regardless of method.

### What if the code doesn't work?

Check the host's game version matches yours, confirm the session is still
open, and have the host re-read the code from the pause menu. Codes are
session-scoped, so closing and reopening the walk generates a new one.
