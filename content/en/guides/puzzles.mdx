## Coordinate leads — solved

The numbers **4166** and **1899** are **map coordinates**, not a code. The
full solution (button location, prerequisites, two-player hold) is on the
[4166 & 1899 Beach Puzzle](/guides/4166-code) page.

## Puzzle types reported

Community reporting describes these puzzle categories on the island:

| Type | Notes |
| --- | --- |
| Coordinate input | Values 4166 / 1899 — **solved** (map coordinates, see above) |
| Peg-board | Layout and solution unconfirmed |
| Item interaction | Carrying / placing objects (matches verified red-figure puzzles) |
| Environmental | Leverage the world itself (echoes, sight lines) |

The item-interaction category is consistent with the verified red bridge
puzzle — the other three remain unconfirmed.
