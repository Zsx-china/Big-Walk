## Session rules

1. Ask before sharing a code.
2. Trust the host display.
3. Avoid rapid retries.

[Read more](#troubleshooting)

## Troubleshooting

- Check both digits.
- Check leading zeroes.
- Confirm the host session is open.
- Wait before retrying.
- Ask the host to repeat the code.
- Join the intended group.
- Ignore reposted public codes.
- Record what changed.
