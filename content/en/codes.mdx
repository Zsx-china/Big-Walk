## Current status

There are currently no official Big Walk redeem codes. Big Walk uses temporary Join Codes instead.

The redemption status is **None announced** (last checked August 6, 2026), which means this page has no official reward-code catalogue to list or maintain. A Join Code is a temporary way for a guest to enter a multiplayer session created by a host, not a coupon, item key, or reward promise; this guide keeps redeeming and joining separate so a player does not expect session access to change an account or unlock content just because the same word, “code,” appears in both discussions.

## What is a Join Code?

A Join Code is a temporary, session-specific code that a host generates so guests can join that host’s multiplayer session, which makes it useful for arranging a particular group rather than advertising a permanent public key. It is a coordination tool for the current group and carries no progress or save data, so a guest should understand the code as an invitation to participate rather than a record of personal achievements. **Pending confirmation:** its format, display location, entry menu, lifetime, and every exception, because the supplied research does not provide enough official detail to turn those possibilities into instructions. Get the code directly from the host you mean to join rather than assuming an old screenshot will work, especially if the group, session, or host’s current plan has changed, because the temporary invitation is useful only when it connects the intended people at the intended time.

## How the host gets a code

The supplied research says that the host generates the Join Code for the intended session, so guests should obtain it from the person coordinating the session rather than from a general code list. The host can share the current session-specific code with invited guests through the group’s usual communication channel, while keeping clear which group and session the invitation refers to. **Pending confirmation:** button names, menu paths, action order, refresh behavior, host conditions, and timing, so this guide deliberately avoids presenting a guessed hosting workflow as a confirmed one. A host can reduce confusion by naming the intended session and confirming whether it is still open when a guest is ready to join, which helps guests distinguish a current invitation from a code that belonged to a different group or earlier attempt.

## How a guest uses a code

A guest uses the temporary Join Code to join the host’s session, not to redeem content or claim a reward outside that session. ## Safety and pending details

Treat a Join Code like a short-lived invitation for a specific group, not a public giveaway or a broadly reusable promise that anyone can enter at any time. Share it only with the people you expect in the session, and check with the host before forwarding it so guests have the same understanding of which session they are attempting to join. **Pending confirmation:** code syntax, host and guest menus, timing, errors, refresh behavior, platform compatibility, and all exceptions, which are intentionally not turned into guessed troubleshooting rules on this page. Use the host’s current code for the host’s current session without promising rewards, permanence, cross-play, or data transfer beyond the facts this guide can support, and return to the host for clarification whenever the group’s plan changes instead of filling a missing official detail with an assumption.
